# 后台逐项填写表：出题人填写，运维照表录入

这就是本题的部署填写单，不需要编写配置文件。表中“本题填写内容”已经按教学样例填好；
**换成自己的题目时，出题人先修改这一列，运维再照表输入。不要让运维猜镜像名、端口或开关。**

- 题目负责人：待填写。
- 审核人：待填写。
- 题面正文：在 [statement.md](../statement.md) 填写，再整段复制到后台“题面”。
- 如何构建镜像和交付文件：填写 [部署交接单](../private/DEPLOYMENT.md)。
- 如有提示：填写 [Hint 填写单](../private/HINTS.md)。
- 想知道某个输入框的意思或默认值：查看 [页面字段说明](FIELDS.md)。

## 第一步：题库管理 → 新建模板 → 基本信息

| 页面上的名称 | 本题填写内容 | 怎么操作 |
| --- | --- | --- |
| 标题 | 文件访问控制 · AWDP V2 教学示例 | 换成正式题目名称，最多 160 字符 |
| 游戏模式 | AWDP | 先选模式，再填写后续页面；不要配置完成后再切模式 |
| 可见性 | 私有(仅负责人/管理员可用) | 编辑已有题目时同一选项显示为“私有” |
| 方向 | Web | 按实际题目改成 Web、Pwn 等，最多 96 字符 |
| 题面 | 复制 statement.md 的全部正文 | 支持 Markdown，不粘贴 PoC、Hint 草稿或部署凭证 |

点击“创建模板”。创建页也有“题目定义”页签；下面统一按创建后的编辑页说明，左侧能看到
“基本信息 / 运行环境 / 模式定义 / 附件 / Flags / 权限”。

### 安全选项（展开后填写）

| 页面上的名称 | 本题填写内容 | 怎么操作 |

| 禁止提权(no-new-privileges) | 开 | 保持开启 |

### Flag 与访问

| 页面上的名称 | 本题填写内容 | 怎么操作 |

## 第六步：Flags、权限和测试

- **Flags**：AWDP 动态容器会显示由平台注入 Flag 的说明，不需要新增精确或正则 Flag。
- **权限**：沿用现有负责人。需要协作者时按实际用户设置“管理员 ID 列表”；这不是题目参数，不应填示例 ID。
- **测试容器**：先保存，再点击“启动测试容器”；查看“访问地址”和“动态 Flag”。保存新镜像或端口后，
  已有实例不会自动更新，要按页面允许的操作重置或重新创建。
- 本教学服务使用固定测试哨兵，尚未把攻击结果接到真实动态 Flag；正式出题必须补好这部分并验收，
  不要仅凭模板能启动就发布比赛。

## 第七步：比赛管理 → 题目 → 该题目

题库填完后还要加入比赛。这里与题库管理是两个不同页面。

| 页面位置／名称 | 本题填写内容 | 怎么操作 |
| --- | --- | --- |
| 添加题目 → 题库模板 | 选择刚创建的题目 | 模式须为 AWDP |
| 基本设置 → 比赛题目名称 | 留空 | 沿用题库标题；只想改本场展示名时再填写 |
| 基本设置 → 顺序 | `10`（示例） | 由负责人确认，不与本场其他题目冲突 |
| 基本设置 → 发布该题目(对选手可见) | 先关 | 完成验收后由负责人打开 |
| 题目配置 → 题目规则 | 不开启任何“覆盖”开关 | 本教学题先继承比赛规则；实际需单题特殊分值时，由负责人填写并审核 |
| 提示 → 添加提示 | 按 private/HINTS.md | 没有 Hint 就不添加，不上传为附件 |

最后分别保存对应页面。计分规则由赛事负责人确认，不是出题人照抄一个示例分数就自动生效。
