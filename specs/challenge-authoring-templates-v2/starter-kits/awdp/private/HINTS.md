# Hint 填写单：按页面录入

这份文件只交给出题人与赛事负责人，不作为选手附件。**Hint 在比赛题目里添加，不在题库模板里添加。**

## 出题人先填

| 项目 | 本题填写内容 |
| --- | --- |
| 是否需要 Hint | 教学示例“有”；正式题目明确填“有”或“无” |
| 所属比赛／题目 | 待填写，运维必须进入正确的比赛题目 |
| 审核人 | 待填写 |
| 何时公开 | 默认先不发布，由负责人确认 |
| 提示数量 | 教学示例 1 条；更多提示复制下方填写表 |

## 提示一：运维逐项照填

页面位置：比赛管理 → 进入比赛 → 题目 → 进入该题 → 右栏“提示” → 点击“添加提示”。

| 页面上的名称 | 本题填写内容 | 怎么操作 |
| --- | --- | --- |
| 提示内容 | 请比较允许访问的公开文件与其他文件在访问控制上的差异，并确认修补不会破坏公开文件读取。 | 正式题目替换成审核过的提示正文，不粘贴完整 PoC 或标准修补 |
| 扣分 | 0 | 免费；需要扣分时由负责人填明确分数，范围 0–1000000 |
| 发布时间(可选) | 留空 | 先保存为未发布；**留空不是立即发布** |
| 保存 | 点击 | 保存后在列表确认内容、扣分和“未发布”状态 |

需要发布时点击该提示的“编辑”，在页面的日期时间控件中选择负责人批准的时间，再保存。
核对操作电脑的本地时区；不要手写 UTC 字符串，也不需要生成 UUID。

没有 Hint 时，不添加任何提示，保留页面“暂无提示”。不要上传本文件，不把提示草稿粘贴进题面。
