# Patch 包模板填写说明

请在 `fix.sh` 中编写你自己的修补步骤，并将需要的替换文件与脚本放在同一个包中。
当前模板尚未实现修补，会明确报错并返回非零退出码，避免把空白脚本误当成有效提交。

平台使用 `/bin/sh /noctf/fix/fix.sh` 执行入口。包内文件位于 `/noctf/fix`，不要依赖调用时的
工作目录。参考教学服务默认位于 `/opt/challenge`；真实题目的允许修改范围以题面说明为准。
不得尝试读取评测凭证、访问宿主机或破坏评测基础设施。

完成修补后，在本目录执行：

```sh
tar -czf ../patch.tar.gz -- fix.sh README.md
```

若增加了替换文件，请在上述命令中逐个列出。归档根目录必须直接包含 `fix.sh`，不能套上
`patch-template/` 目录，不要把之前生成的归档再次打包进去。

提交前请在题目提供的测试环境验证：脚本能够执行、正常业务未受破坏、漏洞确实得到修补。
使用 LF 换行与 POSIX shell 语法，不要使用只能由 Bash 解释的语法。
