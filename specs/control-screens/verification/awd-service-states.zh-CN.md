# AWD 服务灯状态与三栏布局

2026-10-13。

- 每队服务器数量由公开题目目录生成，一道题对应一台服务器；缺少检测数据时仍保留服务器并显示未知。
- 保留灰色机柜，仅原有状态灯变色：正常青绿、被攻陷红色、宕机橙色、未知灰色。右侧状态文字、状态点、服务器灯和二维降级列表使用同一显示状态。被攻陷直接替换“正常”，不再并排显示两种标签。
- 可用性与本轮攻陷在数据上独立。主显示优先级为宕机、被攻陷、正常、未知；攻陷来自当前权威轮次的有效成功 Flag 事实，换轮清除。当前攻陷查询不受历史条数或时间窗口截断影响。缓存保留攻击方来源以过滤非公开队伍，不向公共 API 暴露来源列表。
- 桌面采用左侧窄长排行、中央实时态势、右侧窄长服务状态，三栏等高；底部保留轮次结算。中央镜头按实际透视边界取景，防止较少题目时近处队伍被裁切。
- OpenAPI 与前端 SDK 已重新生成。

## 验证

- 后端观战相关 15 项 TUnit 测试通过，包含真实 PostgreSQL 的 AWD/KoH 两项测试，强制 Docker 可用且无跳过。覆盖当前轮次攻陷、历史窗口外攻击、时间调整、换轮清除、隐藏攻击者与独立服务健康。
- 前端全套 989 项测试通过；之后补充状态灯及透视边界回归，相关 12 项测试通过。类型检查及架构审计通过。
- 浏览器在 1920×1080 检查 32 队、3/8 道题的服务器阵列；三题时右侧恰为 3 项服务，32 个队名均可见且未越界。1366×768 下三栏等高且均在视口内。
- 右侧被攻陷行只显示“被攻陷”，不显示“正常”；机柜材质不随状态变化的行为测试通过。
- 本轮未重新进行长期性能压力测试。
