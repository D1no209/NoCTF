# 题目时间配置实施记录

配置覆盖 CTF、AWD、AWDP、KoH，不覆盖 LiveSolo Round。历史资格使用原受理时间与最新配置比较；版本只用于拒绝过期任务。

## 时间模型、开放与基础判定

- 增加 nullable 开放、计分结束、提交截止字段、自动开放状态和策略版本；EF 工具生成增量迁移。
- 创建与 PATCH 支持时间；省略保留、显式 null 清除。手动提前发布调整开放时间，撤下取消计划。
- 接入 NATS 集群调度、提交后工作及关系化重派发；暂停挂起，恢复补执行，旧任务不覆盖新策略。
- 添加 RightButDue 和独立时间资格；首次 Flag／Fix 完成读取最新时间，分批回算不重新运行 Checker或创建尝试。
- 闯关完成区分合法的不计分成功与时间无效。API／SDK 返回时间配置和选手提交时间资格，补齐基本结果文案。
- PostgreSQL 3 项验证开放／暂停／取消／过期任务、最新资格转换及回滚；规则 4 项和请求缺省／null 绑定测试通过。
- 后端非集成 1520 项通过、1 项按配置跳过；前端 854 项通过，类型与架构审计通过；迁移无漂移，OpenAPI、SDK、Wolverine 适配器均由工具生成。

当前仍须完成：四赛制所有计分投影／明细／导出一致性，历史血榜和有效次数全面同步，管理端影响预览与日期编辑、选手截止交互，以及完整 HTTP／浏览器验收。基础阶段不代表整项功能完成。

## 计分时段过滤

- 计分输入加入当前题目时间，数据库聚合前过滤，避免将截止前后行为合并后误扣分；CTF 明细保留不计分记录。
- AWD 攻击分池与服务结算、AWDP 持续轮次收益及处罚、KoH 检查点使用最新计分边界；归一化明细与总分同步限制。
- 提交、管理记录、已解状态、有效次数和 AWDP 前置条件加入时间资格；时间重判后的明细不沿用旧事件的计分分类。
- 新四赛制计分 4 项测试通过；真实 PostgreSQL 排行榜 14 项和练习 5 项回归通过。修复了新增读取造成的查询次数和集合自动加载告警，未放宽原性能断言。
- 后端非集成 1524 项通过、1 项按配置跳过。仍须完成专用时间影响预览、完整新时间 HTTP／计分回算集成、历史血榜通知及前端浏览器闭环。

## 影响预览、设置与选手反馈

- 管理端采用共享日期控件、时区说明、顺序校验和独立保存；历史影响预览展示队伍分数、血榜、有效正确记录和闯关节点变化。确认令牌绑定用户、候选时间和全部相关聚合并发戳，过期或相关数据变化后重新预览。
- 选手详情展示计分／提交截止时间，以服务端时间校正状态；停止计分后仅验证答案，截止保留输入并禁用发送；Flag／Fix 返回 RightButDue，历史时间无效另说明原因。
- 补齐 Fix 上传的服务端截止检查、最新资格读取，以及迟到 Flag／Fix 评测的血榜通知资格；AWDP 完整轮次与开放边界的总分／明细一致。
- 官方 CLI 重新生成自动开放和历史回算的 Wolverine 静态适配器；真实 Api + Worker + NATS 验收发现并修复调度监控名称和显式处理器发现遗漏，重启后积压回算成功恢复。
- PostgreSQL 专项 5 项（含真实 HTTP 权限／PATCH／预览），排行榜回归 14 项、AWDP 状态回归 1 项、CTF Patch 目标回归 1 项通过。后端非集成 1528 项通过、1 项专用集群按配置跳过。前端 859 项、typecheck 和架构审计通过。
- 已实际检查历史分数 500 → 0 与 0 → 500 的预览、取消初始焦点、390px 窄屏和双语加载。继续完成选手提交、截止与自动开放的真实浏览器闭环后提交验收记录。本记录不表示所有计划验收用例已经覆盖。
