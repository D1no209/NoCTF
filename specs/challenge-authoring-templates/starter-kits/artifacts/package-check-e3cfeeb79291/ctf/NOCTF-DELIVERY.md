# CTF 交付确认

- 题目名称：文档柜，正式交付填写名称。
- 作者、复核人、源码修订：待填写。
- Runtime 镜像完整引用与 digest：待填写。
- 交互：FlagSubmission；Container / PerTeam / PerTeam。
- 本题接口与答案范围：`statement.md`。
- 后台配置：`platform/CONFIGURATION.md`。
- 私有资产：`private/`；公开白名单：`attachment/`。
- Hint 内容与解锁条件：`private/HINTS.md`。
- 实际 ChallengeId、CompetitionChallengeId、隔离比赛与测试队伍：待填写。

## 验收记录

- [ ] Docker 检查通过，记录命令、日期、镜像和结果。
- [ ] 公开附件解包审核，内容和 SHA-256 已核对。
- [ ] Runner 拉取及 TemplateTest 创建、注入、访问与停止通过。
- [ ] 两队 Flag 与权限、Wrong / Correct、重置复用原值通过。
- [ ] 实际计分、血奖、提示、题目时间与生命周期通过。
- [ ] 无活动测试资源；正式题目保持未发布直到复核完成。

失败、跳过和未验收项逐项填写，不预先勾选。不要填写真实 Flag 或凭据。
