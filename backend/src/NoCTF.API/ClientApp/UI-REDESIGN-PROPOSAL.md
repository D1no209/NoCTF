# 全站控件设计改造方案（已批准并实施）

本轮基线：`50b6087f`，上一轮前端架构改动已本地提交。用户已批准本方案。实现期间追加要求：卡片背景与内部控件统一采用 45% 不透明度，恢复 12px 背景高斯模糊。

## 范围

滚动条、选择器只是示例。本轮覆盖公开页面、登录注册、账户、竞赛工作区、管理端、比赛大屏及其弹层，统一重做所有暴露浏览器默认外观或交互的应用控件。

页面和业务视图只使用共享设计系统控件。底层原语仍使用必要的 HTML 语义以支持表单、键盘、输入法、自动填充和辅助技术，但不向用户暴露浏览器默认控件皮肤。文件上传的系统文件选择窗口属于操作系统能力；站内上传入口、拖放区、文件列表和反馈均由共享组件提供。

普通文字与结构布局的 HTML 标签不作为交互控件替代对象。路由离开确认、悬停提示和校验错误等浏览器默认交互也在本轮范围内。

## 视觉方案

建议沿用当前实际代码的 **品牌蓝 + 冷蓝灰**，保留 Inter 与 JetBrains Mono，集中定义亮/暗两套语义色。根 DESIGN.md 已同步为获批方案。

### 卡片

- 全部卡片采用 `20px` 圆角，内部控件采用 `10px` 圆角，卡片图片外沿跟随卡片轮廓。
- 按最新补充使用 45% 不透明度的主题色背景，恢复 12px 背景高斯模糊。
- 光源来自左上，阴影向右下。拟采用接触阴影加投射阴影：静止时约 `1px 2px 3px` 与 `4px 6px 16px`，亮暗模式分别设置透明度。
- 鼠标悬停时上移 `4px`，投射阴影增大到约 `6px 10px 24px`；过渡 `180ms`、ease-out，无弹跳。
- 所有卡片有悬浮反馈；只有可点击卡片使用手形指针。键盘焦点保持清晰，触屏和减少动态效果模式不依赖位移表达状态。

### 滚动系统

- 使用共享自定义轨道和滑块，隐藏浏览器原生滚动条，无上下箭头。
- 正常情况下透明；指针悬停、键盘焦点进入、滚动或拖动时显示。离开并停止滚动后约 `800ms` 隐藏。
- 轨道占宽约 `8px`，滑块视觉宽度约 `4px`，悬停/拖动时加粗；不通过改变内容宽度显示滚动条。
- 滑块使用同色系的主题 token；悬停时提高对比，拖动时使用品牌强调色。
- 页面主滚动、横向表格、菜单、选择器、多行输入及弹层长内容均纳入；保留滚轮、触控板、拖动、触屏和键盘操作，不做惯性滚动劫持。

### 表单与选择类控件

- 输入、下拉框、数字输入、日期时间、上传和弹层均使用同一套背景、边框、焦点、选中与禁用 token。
- 卡片内选择与上传控件背景与主卡片统一采用 45% 不透明度，悬停和聚焦保持一致；文本输入使用 80%，文字与图标保持清晰。主按钮与文字强调色同步，浅色品牌蓝、深色 #39FF14，保留克制光晕，卡片内外使用同一按钮样式；次按钮使用中性色文字和细边框，常态无光晕，禁用状态不发光。
- 建议控件和菜单采用 `10px` 圆角，与20px 圆角卡片协调；常规高度 `40px`，紧凑模式 `32px`，触屏热区至少 `44px`。
- 宽表单使用按内容区分的共享宽度上限：数量 192px、日期 320px、选择器 384px、文本 576px、多行输入与上传区 672px；以表单容器宽度 576px 为分界，窄卡片恢复可用宽度。预览采用名称/数量及日期/选择器分行并排，手机端单列；上传按钮按内容宽度显示。
- 下拉菜单采用不透明主题面板；选中项使用品牌色浅底与勾选标识，悬停、键盘焦点和选中状态可区分。长列表使用共享滚动系统。
- 日期时间选择使用自定义日历、月份导航和时间输入；保留现有本地时间与 API 序列化契约。
- 日历日期按钮默认 44×44px，月份/年份触发器、导航及下拉选项高 44px；顶部导航不覆盖选择器。极窄屏日期格收缩至 39px，避免弹层横向溢出。鼠标光源使用主题色径向渐变，逐帧合并指针位置更新、移出淡出，不拦截点击；触摸和减少动态效果模式不显示。
- 数字输入使用自定义加减操作，不暴露浏览器步进箭头，不因普通页面滚轮意外修改值。
- 文件上传采用统一按钮或拖放区，展示文件名、大小、进度、错误及移除操作；原生文件 input 仅作为隐藏的系统接口。
- 表单关闭浏览器默认校验气泡，使用 FieldError/错误摘要与首次错误定位；规则与异步校验仍属于功能层。
- 站内确认和提示使用共享 Dialog/Tooltip。按钮、菜单与通知同时覆盖默认、悬停、按下、焦点、加载、禁用、成功、错误状态。

## 主题一致性

卡片、表单、弹层、菜单、滚动条、通知、图表和大屏都从同一套 token 取色。品牌蓝承担操作与焦点；成功、危险、警告及题目分类颜色保留各自语义，统一映射和亮暗适配。业务视图不得自行定义颜色、阴影或控件状态皮肤。

## 实施与验收

1. 更新共享 token 与原语，先验证亮/暗两套完整状态。
2. 补齐 Form、NumberField、DateTimePicker、上传、Tooltip 等缺失控件，并迁移所有调用。
3. 统一页面、表格、选择器及弹层的滚动宿主，检查嵌套滚动、粘性表头与弹层裁切。
4. 将大屏、图表与动画中的局部颜色接入主题。
5. 扩展架构检查，拦截业务视图中的原生表单、原生选择类型、DOM title 提示、浏览器对话框和局部控件皮肤。
6. 验证中英文、亮暗主题、键盘、触控、小屏、减少动态效果，以及现有业务回归、类型检查和静态构建。

## 已批准的设计取值

已批准品牌蓝/冷蓝灰方向，以及卡片上移 `4px` / `180ms`、阴影强度、滚动条 `800ms` 自动隐藏、其他控件 `10px` 圆角和常规 `40px` 高度。20px 圆角卡片、右下阴影、全站自定义控件和统一主题均已落地；卡片面板按最新补充使用 45% 不透明度与 12px 背景高斯模糊。

## 后续补充（已实施）

错误提醒、校验摘要与通知统一改为右下角小型弹窗，从右向左滑入；使用 14px 微软雅黑、700 字重和 SVG 状态装饰。字段保留错误标记、可访问性关联和定位入口。开发环境保留 `/__ui-check` 供查看效果，发布构建排除此预览路由。

最新补充：开发预览背景改为多色拼接；卡片 20px 圆角，内部控件 10px 圆角，并加入轻量 SVG 装饰。卡片与卡片内选择、上传控件保持 45% 背景不透明度，文本输入使用 80%，并恢复 12px 背景高斯模糊。
