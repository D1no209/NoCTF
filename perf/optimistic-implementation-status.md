# 乐观评测实施与验证记录

更新日期：2026-10-19。实现、关系数据库测试和容量验收分别记录；整体优化尚未完成验收。

## 本轮代码

- 评测消息使用事实最后一次保存后的 `ConcurrencyStamp`；普通 Flag 受理使用 ReadCommitted，次数资格由 Worker 判断。
- 普通 Flag 请求绕过数据库配额租约和共享 IP 窗口；其他受保护操作保留原配额。连接预算未增加。
- 路由器将已读取的事实传给普通评测器，避免重复读取。完成 UPDATE 仍使用事实并发标记。
- 删除排行榜 Handler 对理论题和 WriteUp 的完成写入；业务结果在各自入口持久化后完成。
- 修正 AWD 管理判定、Checker 待裁决、Patch 受理和 LiveSolo 判定/纠正通知的保存后版本。
- 错误及次数超限结果不再发送解题 Runtime 清理消息；ManualAdjustment 跳过题目配置、定义与 Flag 判定查询。
- 无配额获取返回轻量句柄，不打开数据库连接；请求取消令牌仍生效。
- 题目详情直接投影 Runtime 能力与交互类型，避免加载完整 Runtime/Checker 定义；没有 Hint 时跳过解锁历史查询。
- 增加缺失、旧版本、已完成消息、完成竞争及有效完成指标，并记录完成阶段耗时。
- 删除 Hint/每队 Flag 的空 `TeamChallengeCriticalSection` 包装及其额外队伍查询、两秒计时。Hint 原资格查询、外键和各自事务仍然保留。
- 删除理论分数投影中的完成回执和对应事实子查询，投影不再反向完成事实。
