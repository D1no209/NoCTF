# 选手场内操作与判胜

只有当前锁定名单中的合格成员，在允许的 Match/Round 状态下可使用此工作区。普通 CTF 题目页和提交接口不处理 LiveSolo 场内作用域。

## 题目开放与选择

双方收到相同 RoundQuestion，并在同一服务器实际时间开放。后续题目出现后，先前题目仍可有效提交；当前选题和 Flag 草稿由每位成员自己保持，不由队友切题强制覆盖。

查看题面、免费提示和已开放列表。LiveSolo 提示不收费，不写普通提示解锁得分事实；隐藏或未开放内容仍不可读取。

## 附件

使用当前题目的原生浏览器下载入口。随机附件分配、成功获取证据按本队和 RoundQuestion 作用域保存；只浏览列表或准备下载不算已经获取文件。

下载失败核对实际传输与授权，不能拿其他 Match、旧 Round 或模板测试的文件/记录补充本场获取证据。同队当前作用域可共享合法分配。

## Runtime

通过场内环境操作读取、启动、UUID 重置或停止已开放题目的目标，使用当前返回的访问入口。正式 Runtime 需要验证的隔离能力，通常走 WsrxOnly，不在模板中公开另一条绕过隔离的直连路径。

Round 控制作用域有效期，不能把模板 TTL 当成提前结束本场目标的唯一计时依据。重置得到新 Runtime UUID，当前投影和历史 Flag 窗口由服务器处理，不复用旧连接冒充新环境。

## 提交 Flag

完整输入当前答案并提交一次，查看 GameplayFact ID 和 admissionSequence，随后等待最终评测。请求有幂等身份，网络超时先确认受理，不连续制造多个新尝试。

同一 Round 中双方、所有成员和所有题目的受理序号共同排序。**第一条当前有效正确 Flag 获胜，不按评测完成速度、浏览器回车时间或网络返回先后判胜。** 后受理但先评完的答案不会抢走更早有效答案的胜局。

## 时限、暂停与重赛

到时先排空截止前已受理记录，再决定结果；页面 ConfirmingResult 不表示已无条件判平。Match 暂停与比赛暂停取时间并集，不重复加暂停秒数。

Void Round 不加胜局、不消耗有效 BO 局数。重赛有新 Round/题目/Runtime 作用域和适合的新题组，旧 Flag、附件及获取证据不可跨作用域搬用。

本模式没有普通积分、血奖、提示扣分和题解收益折扣。成绩看 Match 胜局与赛程，赛后内容从 [专用题解目录](./postgame.md)读取。
