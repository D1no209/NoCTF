# 排行榜队伍详情修复

## 展示与数据

- 原先 DialogScrollContent 只限制最大高度，未限制子内容溢出，图表和长列表越出弹窗背景。改为固定边界的 DialogContent，外层 overflow-clip、内层独立纵向滚动，标题和关闭按钮始终可见。
- 长题目名换行；时间、分数不换行。窄屏仅在表格内部横向滚动，不将弹窗撑出屏幕。
- CTF 下方列表仅列成功解出的题目，显示首次成功者的公开昵称（UserName）和提交时间；不以分数是否大于零判断解出，因此人工调分不制造解题记录，扣分也不会抹去成功记录。
- AWDP 每道题按首次攻击／防御成功分别展示操作者与时间。仅攻击或仅防御成功也会出现；失败尝试不出现。防御仍遵循 RequireBreakBeforeFix 的先后条件。
- 保留原有总分、雷达图和队员得分占比的统计范围，过滤只作用于下方题目明细。

现有排行榜响应的队伍对象新增 achievements，不新增接口或业务表。汇总来自服务端全历史有界事实摘要，不依赖只有 5 条的矩阵摘要或当前轮次窗口。仅使用 Completed + Correct，按时间、事实 ID 选取首次成功。公开题目和赛道过滤仍沿用原有投影路径，不暴露姓名、学号、IP、Flag 或 Patch 内容。

缺少新字段的旧实时缓存会走现有缓存重建流程；冻结榜仍按冻结时间投影，不读取冻结之后的成功事实。遇到缺少归属数据的旧快照，前端明确提示，不猜测解题者。

## 验证

新增 CTF 摘要截断、人工调分、评测中排除、首次成功归属，以及 AWDP 超出当前轮次窗口、独立防御成功的测试。真实 PostgreSQL 回归验证昵称来源、未公开题目隔离和历史时间精度。浏览器本地夹具验证长列表、CTF／AWDP 攻防归属、零解题空态、390px 手机深色模式、标题和关闭按钮不随正文滚动。

仅本地提交，不推送、不部署；无需数据库 Migration。
