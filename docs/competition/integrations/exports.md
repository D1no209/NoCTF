# 赛事事件与归档导出

入口：比赛管理 → 导出，`/admin/competitions/比赛ID/exports`。下载需要当前授权，普通访问令牌不自动拥有管理归档权限。

## 事件 JSONL

选择起止时间并导出 `competition-比赛ID-events.jsonl`。时间输入按本地显示转换为服务器 ISO 时间，不能只填写一端，也不要混用不同时区的截图时间。

JSONL 一行一条记录，适合逐行核对和分析；它不是整个文件一个 JSON 数组。数据范围遵循导出契约和读取权限，不保证含全部私密技术内容。

操作步骤：选择明确窗口 → 导出 → 等待实际下载 → 检查行数、首末时间、比赛 ID → 在受限位置保存。Finished 后的申诉、题解与纠正若也需交付，窗口必须覆盖这些实际发生时间。

## 比赛归档 ZIP

点击归档导出，选择是否包含受保护 Flag。普通归档与含 Flag 归档有不同敏感级别；未勾选不能被解释为所有原始值均存在。

包含受保护 Flag 需要平台 Administrator，当前界面要求填写 8–512 字符原因；普通 Owner/Manager 的归档权限不包含此特权。核对接收者和数据保管，再下载 `competition-比赛ID-archive.zip`。不把 Flag 归档用作公开成绩附件。

平台使用授权同步流式响应，没有“data_exports 后台任务”或自动邮件投递。导出开始提示不是下载完整性证明；浏览器/代理中断后验证 ZIP 可打开并核对内容，再重试。

## 三种归档分别用于什么

| 下载 | 主要用途 | 不能替代 |
| --- | --- | --- |
| 事件 JSONL | 追溯赛事窗口事件 | 全量数据库/附件恢复 |
| 比赛 archive ZIP | 业务资料归档和审查 | 离线 JetStream/平台密钥备份 |
| [一致恢复点](../../operations/backup.md) | 灾难恢复与版本回退 | 无审核公开成绩发布 |

需要运行流量另去 [抓包导出](../operations/traffic-captures.md)，平台技术日志去 [日志页](../../platform/maintenance/logs.md)，平台审计去 [审计归档](../../platform/maintenance/audit.md)。

## 导出失败

核对令牌/权限、起止时间和受保护原因。大型导出检查代理流式传输与超时、存储读取和客户端磁盘，不为导出放宽数据库或 Loki 公网访问。
