# 题目自动开放、计分结束与提交截止

入口：普通比赛题目详情的时间设置。适用前四赛制；LiveSolo 使用 Round 的相对开题与时限，不显示这组绝对时间编辑。

## 三个独立字段

| 字段 | 含义 |
| --- | --- |
| AutoOpenAt | 题目计划自动开放时间 |
| ScoringEndsAt | 该题正式计分截止，之后仍可能只判定不计分 |
| SubmissionDeadlineAt | 正式提交截止，之后不再按普通窗口收新提交 |

日期按页面显示时区输入，发送为 ISO 绝对时间。已填写时应满足开放不晚于计分/提交截止，计分截止不晚于提交截止。清空与填写某个时间是不同政策，保存后读取有效值，不猜空值等于现在。

例如计分 18:00 结束、提交 18:30 截止：18:00 后至 18:30 的有效请求可处于只判定阶段，不增加正式成绩。比赛自身状态、资格、题目发布和访问规则仍要同时满足。

## 先预览后确认

1. 修改三个时间并保存，系统先取得影响预览。
2. 查看受影响尝试、队伍和计分变化。
3. 有历史影响时阅读确认，使用当前 preview token 应用。
4. 保存后检查 recalculationPending；等待权威重算完成再发布成绩。

修改候选时间会让旧预览失效。并发变化或预览过期时重新预览，不把旧确认 token 再用于新时间组合。

## 选手界面和练习

页面根据服务器时间快照显示提交已关闭或只判定状态，浏览器时钟不是最终授权。CTF Practice 有独立赛后边界，不因普通正式提交截止而产生正式分或血奖。

单题题解截止、整场 PDF 截止与 Flag/补丁提交截止各自配置，勿把 SubmissionDeadlineAt 当作全部上传的同一截止。时间变更需公告明确日期、时区、正式计分和可提交范围。
