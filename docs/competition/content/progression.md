# CTF 闯关与勋章

闯关只适用于 CTF，默认关闭。比赛管理“闯关与勋章”将题目与勋章类型导入图，使用前驱条件控制可访问题目。勋章不增加分数。

## 1. 创建勋章类型

先创建勋章目录项，填写名称并上传图片。勋章目录独立于保存的图，创建类型不代表已经授予队员。

为勋章写清含义，例如完成入门分支或完成某组题目。图片需是受支持文件并通过上传验证。

## 2. 构建图

1. 将已配置的题目和勋章从左侧目录手动导入画布。
2. 为需要依赖的节点添加有向连接。
3. 每条边选择要求来源节点“已完成”或“未完成”。
4. 检查没有自连、重复边、不存在节点或循环。
5. 需要时开启选手只读图。
6. 保存闯关图并启用规则。

同一题目最多一个图节点，同一勋章类型可有多个节点。条件针对**来源节点实例**，默认所有入边同时满足才激活目标，没有入边则无条件激活。

## 画布、批量连接与勋章编辑

选择节点/连接后修改其属性，可拖动布局、缩放和自动排列；自动排列仅整理位置，不自动决定哪些题目需要连线。删除选中的图节点不等于删除题库或比赛题目。

批量连接时先选择来源、边条件，再勾选目标节点，检查预览后应用。取消批量编辑不会保存关系；循环、自连或重复边仍会被服务器拒绝。应用后点击保存闯关图才提交。

勋章类型支持创建、改名/换图和删除。先更新目录项，再检查画布里该类型的实例引用；不能删除仍被使用的类型后假装节点继续有效。图片上传、目录保存和图保存分别核对。

## 示例：完成入门后开放进阶

将“入门题”连接到“进阶题”，边要求入门节点已完成；再把入门题连接到“入门勋章”节点。队伍入门题当前正确后，进阶题开放，勋章节点激活。

使用“未完成”条件时要特别审查图变化：它可以让一个分支完成后另一个分支重新锁定，而不是只增不减地解锁。

## 节点的前驱开关

关闭某节点“需满足前驱条件”后，即使图整体启用，该节点也直接激活。入边仍保存并展示，节点完成与出边判断仍按原规则。无需让选手执行额外“提前解锁”。

## 保存立即生效

保存会重新计算当前队伍状态。若并发返回 409，重新载入最新图，合并自己的编辑后再保存，不直接覆盖另一个管理员的更新。

图修改可以让已解题再次锁定，但保留正确事实与分数。锁定题目隐藏详情、附件、提示，并阻止新提交、新环境或续期；已存在的直连 Runtime 不因图变化立即强制结束。

## 勋章授予和撤销

同一类型只要任一实例激活，类型即激活。由失活变激活时，只向当时队伍有效 Human 成员授予；后来加入者不自动补发。重新失活会撤销该队该类型的当前授予，包括离队成员；再次激活使用新的成员快照。

关闭整个闯关规则会撤销当前勋章并恢复普通题目访问。赛后练习正确事实也可以重算闯关，不能把勋章当作正式比分证明。

## 正式启用前

在隔离比赛验证正常解锁、反条件重锁、勋章撤销、新成员不补发、保存冲突与选手图可见性。正式运行中编辑前告知队伍可能的访问变化，并保留备份和管理员值守。
