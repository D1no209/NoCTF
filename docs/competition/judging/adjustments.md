# 人工调分与结果核对

入口：队伍详情、比赛题目详情、题解审核中的调分动作。它创建 ManualAdjustment 事实；原 Flag/Fix 判定保持独立。

## 调分之前

确认比赛、队伍和题目 UUID、当前有效成绩、资格、赛道与榜单可见性。公开 Frozen 榜不是最新管理成绩，不按它计算补偿。

修正评测逻辑错误使用重判；修正配置规则使用模式配置；需要独立裁定加减分时才用人工 delta。单纯缓存慢不是调分理由。

## 输入规则

| 输入 | 结果 |
| --- | --- |
| `25` | 增加 25 分 |
| `-10` | 减少 10 分 |
| `0` | 无效，不创建零调整 |
| 小数、超出 Int32 的值 | 无效 |

有效范围 -2147483648 至 2147483647，并且非零。按页面选择队伍/关联题目、输入裁定理由，提交前再次核对正负号。系统以 canonical signed Int32 文本存储业务边界，不用另一栏“总分”覆盖历史。

## 操作步骤

1. 从当前队伍/题目打开调整弹窗。
2. 选择正确作用域并输入 delta 和理由。
3. 阅读当前权威分数，确认一次操作的预期净变化。
4. 提交，保存受理的记录/时间。
5. 等待榜单刷新，并在当前事实中检查调整。
6. 向队伍说明公开裁定范围，私密证据留在授权咨询/审计。

网络超时后先读列表，确认是否已有调整。再次提交可能产生另一条事实并重复加减分，不用重复点击催促异步投影。

## 题解“扣至零”

审核页按某题当前净分创建相反数 delta，将当时净额调到 0。它不是永久锁定该题成绩，后续曲线、资格、重判或其他调整仍可能变化。权威分数读取失败时先恢复投影，不对猜测值扣分。

## 核对与纠正

检查基础分、血奖、提示/错误罚分及全部人工调整，再看最终总分。误调后按管理流程记录反向调整和原因，不删原提交冒充未发生；具体允许动作以当前授权接口为准。

成绩发布前处理仍在 Pending 的评测、封禁/申诉和题解裁定，等待投影就绪，再导出明确时间的结果。
