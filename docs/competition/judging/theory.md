# 理论答卷审核与纠错

在比赛理论答题页或独立理论活动详情中，打开“答卷与成绩”。这里处理理论试卷；普通 Flag 重判、实践题人工调分和 LiveSolo 结果纠正分别使用自己的入口。

## 查询与预览

先定位参与者/队伍和试卷，核对活动 ID、尝试次数、试卷状态、交卷时间、原始得分及当前有效成绩，再打开授权预览。分页读取时保留当前筛选条件，不把第一页当成全部答卷。

工作人员权限决定可见范围。比赛 Judge 可在授权范围预览并发起私密咨询；Observer 不读取答案键或内部赛道试卷；正式纠错由有管理能力的人员执行。图片逐次鉴权，不能把工作人员预览地址转发给选手。

未交卷、已交卷零分、作废、等待处理是不同状态。网络超时后先重新读取，不通过重复交卷或额外调分“补救”未知结果。

## 处理咨询

核对争议对应的实际试卷版本和选项，必要时从审核界面发起私密咨询，填写问题与依据。不要在公开公告中发布题面、答案键或其他队伍的作答内容。沟通记录不自动改变成绩，需要正式纠错时继续执行下述流程。

## 答案纠错或统一给分

1. 选中活动使用的具体题目版本，确认影响范围；同名题或题库最新版本不一定是本次发卷版本。
2. 选择修正正确答案集合，或对此题统一给分。统一给分也可能改变原本未答或答错者的成绩。
3. 生成影响预览，检查所有受影响队伍/参与者的原成绩与预计成绩，并考虑最高分、最后一次、累计的聚合差异。
4. 填写原因，在预览有效期内确认应用。预览过期、状态变化或出现新版本时重新生成，不能沿用旧确认。
5. 记录返回的处理目标，等待批量重算完成。已受理不等于全部试卷和排行榜已更新。
6. 重新查看代表性答卷、活动成绩和比赛榜单，并检查操作记录。若后台仍在处理，调查 Worker/NATS 状态，不反复提交相同纠错。

纠错保留活动的当前覆盖规则及审计，后台按目标修订处理，旧任务不能覆盖更新的纠错。修改全局题库只影响后续使用，不代替这里的正式成绩修正。

## 作废单份答卷

定位准确试卷，查看其对当前有效成绩的贡献，填写原因并确认作废。作废后重新核对聚合成绩：最高分可能退回其他有效答卷，最后一次和累计也会重新计算。

作废保留试卷、次数和已用题源记录，不等于删除或返还机会。需要停止后续答题时还应检查活动运行状态，不能仅靠作废一份答卷达到停止发卷的目的。

## 审计与异常排查

在“操作记录”按时间查找发布、暂停、延期、停止发卷、结束、作废、曝光接受和纠错记录，保留活动、试卷、题目版本及重算目标 ID。

榜单冻结时，工作人员看到的当前成绩与公开截面可能不同；先核对可见性政策。若答卷已完成而榜单仍旧，检查投影和缓存恢复；若重算未完成，检查持久任务处理。故障记录只包含安全错误摘要，不记录原始答案键或受保护图片地址。
