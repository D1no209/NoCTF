# 队伍题解审核

入口：比赛管理 → 题解，`/admin/competitions/比赛ID/writeups`。读取、调分与发起咨询按当前角色区分；Observer 可以只读，但不能据此获得所有裁定动作。

## 开始审核前

在 [基本设置](../settings/basic.md)核对题解是否必交和截止时间。EndAt + 扩展小时是最终截止，不能仅告诉队伍“结束后再交”而不说明日期/时区。

选手提交的是全队当前一份有效 PDF，成员可在截止前替换。审核系统不承诺每次上传都有永久历史版本；记录文件 SHA-256 和提交时间作为本次审核依据。

## 列表与文件

1. 在左侧选择提交队伍，检查是否还有未提交队。
2. 读取文件名、大小、提交账号/时间和 SHA-256。
3. 在线预览，必要时下载到受控位置。
4. 核对 PDF 覆盖的题目、解题过程与当前成绩。
5. 若文件变化，重新确认当前版本再继续裁定。

只改扩展名不是 PDF。预览失败时确认原下载是否完整、文件格式与浏览器渲染；格式失败与成绩读取失败分开处理。

## 当前成绩与人工裁定

审核页显示题目得分、总分及调整前后信息。它使用权威计分投影，加载失败时 PDF 仍可能可读，但不要用旧分值调分。

可以为某题扣除当前得分，或输入非零 signed Int32 独立 delta。先阅读 [人工调分](./adjustments.md)，确认受理后等待权威刷新；“同步超时”先查询事实，不重复提交。

## 快速咨询

选择整份题解或关联具体题目，填写清晰标题和问题，例如请求解释某一步证据。当前表单要求标题和内容至少 4 字符，提交后进入队伍私密咨询线程。

全队按线程权限回复，其他队不能读取。不要将裁定证据放进面向全体选手的公告；查看 [咨询处理](../communication/questions.md)。

## 截止与交付

截止后选手不能补交/替换，已有文件可按权限查看/下载。若赛事不强制提交，未提交不自动形成某种平台扣分；规则裁定由组织者按已公布政策处理。

交付最终成绩时记录所审核文件、最终调整事实和解决的咨询。导出 archive 与数据库恢复点不同，见 [赛事导出](../integrations/exports.md)。
