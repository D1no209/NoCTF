# 题解审核

入口：比赛管理 → 题解，`/admin/competitions/比赛ID/writeups`。读取、调分与发起咨询按当前角色区分；Observer 可以只读，但不能据此获得所有裁定动作。

## 单题题解设置与审核

审核工作区的“单题题解”和“整场 PDF”分别管理独立的数据。单题题解覆盖 CTF、AWD、AWDP、KoH，关联比赛题目实例。既有比赛默认关闭，必须在比赛配置或题解设置中明确开启。

| 设置 | 默认值与范围 |
| --- | --- |
| 启用单题题解 | 关闭 |
| 默认收益扣分比例 | 20%，整数 0–100 |
| 单题投稿截止延长 | EndAt 后 24 小时，0–8760 小时 |
| 单题比例覆盖 | 默认继承比赛，可在比赛题目设置覆盖或恢复继承 |

实际截止日期随结束时间和延长小时显示。整场 PDF 的必交与期限不影响单题投稿。关闭功能保留版本和扣分记录；工作人员仍可审核历史，选手入口和正文访问关闭。

1. 按题目、队伍、来源和状态搜索投稿。URL 保留筛选、页码与选中项。
2. 核对题目、队伍、提交者、版本和时间，再预览 Markdown 或 PDF。可切换投稿版、公开版和对照；Markdown 显示行差异，PDF 并排预览。
3. Judge 可填写原因退回投稿或发起私密咨询；Observer 只读。平台管理员、比赛所有者和 Manager 可以公开或撤下。
4. 公开前确认题目、作者、版本与适用比例。赛中公开会让选手取得答案。新版本退回不撤下旧公开版本。
5. “官方题解”允许每题维护一份官方内容，复用草稿、投稿和发布流程，工作人员维护不受队伍截止时间限制。

投稿后内容不可变，修改创建新草稿。不要用人工调分替代自动题解折扣。撤下阻止后续正文、预览和下载；重新公开不会给已解锁队伍重复收费。

## 单题查阅的成绩影响

首次正式查阅他人内容保存全队共享的比例快照。当前与后续收益均按 `ceil(G × p / 100)` 扣除；后续政策改变仅影响未查阅队伍。

| 赛制 | 正向收益 G |
| --- | --- |
| CTF | 解题收益及查阅前取得的血榜奖励 |
| AWD | 攻击与服务存活收益 |
| AWDP | Break 和 Fix 收益 |
| KoH | 控制收益 |

既有罚分、提示费用和人工调分不折扣。明细分摊取整余量，完整题目净分与排行榜总分一致，不用当前轮次窗口代替完整成绩。CTF 查阅后产生的解题失去血榜资格；以原提交时间判断，异步评测和重判不会改变这个时间边界。

赛前不开放公开正文；暂停只允许已解锁或本队内容；赛后免费阅读不改变正式成绩。首次确认前不返回正文、摘要或 PDF 文件地址。PDF 无法打开时不记录新查阅，已提交凭据的网络重试不会重复扣分。

发布验收应使用普通已审核参赛账号，检查首次确认、同队另一成员读取、比例快照、撤下再公开、功能关闭再开启及赛后阅读。题解读取不会补造静态 Flag 的下载或容器启动证据。

## 整场 PDF 审核

## 开始审核前

在 [基本设置](../settings/basic.md)核对题解是否必交和截止时间。EndAt + 扩展小时是最终截止，不能仅告诉队伍“结束后再交”而不说明日期/时区。

选手提交的是全队当前一份有效 PDF，成员可在截止前替换。审核系统不承诺每次上传都有永久历史版本；记录文件 SHA-256 和提交时间作为本次审核依据。

## 列表与文件

1. 在左侧选择提交队伍，检查是否还有未提交队。
2. 读取文件名、大小、提交账号/时间和 SHA-256。
3. 在线预览，必要时下载到受控位置。
4. 核对 PDF 覆盖的题目、解题过程与当前成绩。
5. 若文件变化，重新确认当前版本再继续裁定。

只改扩展名不是 PDF。预览失败时确认原下载是否完整、文件格式与浏览器渲染；格式失败与成绩读取失败分开处理。

## 当前成绩与人工裁定

审核页显示题目得分、总分及调整前后信息。它使用权威计分投影，加载失败时 PDF 仍可能可读，但不要用旧分值调分。

可以为某题扣除当前得分，或输入非零 signed Int32 独立 delta。先阅读 [人工调分](./adjustments.md)，确认受理后等待权威刷新；“同步超时”先查询事实，不重复提交。

## 快速咨询

选择整份题解或关联具体题目，填写清晰标题和问题，例如请求解释某一步证据。当前表单要求标题和内容至少 4 字符，提交后进入队伍私密咨询线程。

全队按线程权限回复，其他队不能读取。不要将裁定证据放进面向全体选手的公告；查看 [咨询处理](../communication/questions.md)。

## 截止与交付

截止后选手不能补交/替换，已有文件可按权限查看/下载。若赛事不强制提交，未提交不自动形成某种平台扣分；规则裁定由组织者按已公布政策处理。

交付最终成绩时记录所审核文件、最终调整事实和解决的咨询。导出 archive 与数据库恢复点不同，见 [赛事导出](../integrations/exports.md)。
