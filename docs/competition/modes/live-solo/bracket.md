# 赛程、种子与手动对局

入口：`/admin/competitions/比赛ID/live-solo/bracket`。工作人员在竞赛管理工作区查看赛程；管理者可配置种子和对阵，裁判、观察员只读。选手在选手大厅查看公开的当前对阵。

## 生成淘汰赛

1. 检查比赛配置中的单败/双败和阶段胜局。
2. 从合格队伍中选择参赛名单，核对队伍 UUID。
3. 调整种子顺序，不只改变屏幕上的显示排序。
4. 预览/确认生成，使用当前赛程版本标记。
5. 读取 Winners、Losers、决赛和条件重置决赛等实际来源关系。

轮空不是一次实际失败。未决来源的 Match 等待上游结果，不需要管理员临时填一个对手冒充晋级。双败按实际失利和条件决赛规则处理，不能把两次任意管理操作当作两次败场。

## 手动 Match

选择左右两支不同有效队伍和 requiredWins，确认后进入新对局。手动对局与淘汰赛的冠军/晋级关系不同，不用手动赢局冒充已生成赛程冠军。

同队同时只能占一个活动 Match；两队淘汰赛中不能用额外手动局绕开赛程。已暂停的首次倒计时仍可能占用并行名额。

## 查看与推进

后台“对局管理”按对局显示当前状态、双方和胜局，进入对局处理名单、准备与局。完成后由权威结果推进赛程；列表刷新失败时先重读，不重复点击生成。

结果有争议时使用 [纠正流程](./corrections.md)，它会分析下游影响。不能直接在普通积分榜补分来修改胜者或晋级来源。

## 验收边界

规则和原子晋级已有对应测试，不等于完整现场赛程、多节点恢复或纠正后真人重赛已经验收。按 [就绪清单](../../../operations/live-solo-readiness.md)验证目标队伍规模及单双败场景。

## 工作区导航

工作人员从竞赛管理侧栏进入对局管理、本场题目池、题单、赛程或赛制与直播设置，操作期间始终保留管理侧栏。比赛基本设置继续负责名称、时间与报名等通用信息。

管理页右上角可明确打开选手大厅或对应的选手对局；选手视图不会因为当前账号有管理角色而自动变成工作人员视图。

从对局返回列表会保留选中对局；录像、题解和结果纠正返回对应对局。题单编辑与题目池之间往返保留草稿和新增题目选择，未保存内容会在离开时提示。
