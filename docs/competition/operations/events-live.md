# 赛事动态与大屏

入口：比赛管理菜单中的动态、大屏/控制屏，也可从比赛工作区进入。路由分别为 `/competitions/比赛ID/events`、`/competitions/比赛ID/live` 和 AWDP 的 `/competitions/比赛ID/awdp-live`。

## 动态、播报与消息

| 界面 | 展示目的 |
| --- | --- |
| 赛事动态 | 当前用户有权读取的不可变比赛操作与结果事件 |
| 题目赛事播报 | 开放、提示、题面更新、血榜、公开作弊纠正等紧凑事件 |
| 个人消息中心 | 与本账号/队伍/管理职责有关的通知 |
| 大屏 | 面向观众展示公开比赛进展 |

不要把公开血榜广播描述为“你的队伍得奖”，也不要用个人消息中心代替完整比赛事件调查。

## 查看动态

根据事件类型、时间和关联资源定位，再打开关联题目/队伍/事实。重连后重新读取，SignalR 只提示失效，不保证每次事件都逐条送达。

比赛 Finished 后仍可发生题解、申诉、纠正等合法管理事件。动态查询不应该按结束时间截掉这些记录；查询实际处理发生时间，留意浏览器与服务器时钟差。

## 大屏使用

1. 选择正确比赛与对应模式入口。
2. 在独立展示浏览器打开，检查标题、状态、当前轮次和榜单范围。
3. 按页面能力启用全屏/刷新。
4. 验证实际成绩变动和断线恢复，不只看动画运行。
5. 现场展示保持普通公开读取范围，不投屏管理敏感页。

CTF 3D 视图可呈现题目和解题进展；AWDP 控制屏按 Break/Fix、轮次和队伍动态组织。当前菜单仅向对应 CTF/AWDP 提供其大屏，AWD/KoH 不冒充 CTF 3D 内容。

LiveSolo 使用独立 [大厅/赛程](../../live-solo/bracket.md)和 [延迟节目](../../live-solo/program.md)，不进入普通积分排行榜或 CTF/AWDP 大屏。观众不接收裁判当前私有状态。

## 冻结与隐藏

大屏、公开播报和 Webhook 应遵守公开投影。Frozen 不代表未判，Blackout 不对外暴露血榜。管理者需要调查时另用授权事实页，不能通过展示账号绕过可见性。

事件导出见 [导出说明](../integrations/exports.md)，技术性能与连接排障见 [运维排障](../../operations/troubleshooting.md)。
