# 题目方向目录

入口：比赛管理 → 方向，`/admin/competitions/比赛ID/directions`。用于题目列表分组、分类图标及显示顺序，不控制队伍报名和计分资格；这些属于 [赛道](../participants/tracks.md)。

## 字段和约束

| 字段 | 配置规则 |
| --- | --- |
| 方向 ID | 每个方向的稳定身份，创建后关联题目 |
| 名称 | 非空，最长 96 字符；同目录不使用重复名称 |
| 图标 | 当前安装 Lucide 包中可用的图标名称，不能填任意 SVG/URL |
| 排序 | 目录中的排列顺序，影响题目分类展示 |

目录保留 1–64 个方向。模板自己的方向文本与比赛题目引用的方向目录 ID 不同，引用模板后检查比赛题目归类是否正确。

## 新增、编辑与保存

1. 进入方向页，读取当前目录。
2. 点击新增，填写名称和可用图标。
3. 按界面顺序整理目录，避免同名方向。
4. 点击保存，完成全目录更新。
5. 回到题目页选择方向，并用选手列表检查分组/图标。

未保存的新增项不代表已经被服务器认可。图标错误时改用当前可选图标；不能只写“Web”就假设同名图标存在。

## 删除方向

最后一个方向不能删除。仍被比赛题目引用的方向不能删除，检查包含已删除题目的引用，不只看当前已发布题。

先将引用题目改到保留方向并保存，再删除空方向。若仍返回 DirectionInUse，核对已删除题目或后台引用；不能直接改数据库清外键。

## 常见问题

- 保存失败 NameConflict：名称或身份重复，整理目录再提交。
- 图标不可用：使用当前版本支持的 Lucide 标识，排除错误前缀/拼写。
- 列表仍显示旧分类：先确认目录保存成功，再刷新题目和公开视图。
- 选手资料方向统计变化：当前公开已开赛题目目录参与公开画像，方向变化也影响展示，不等于改变历史成绩。
