# 创建比赛与管理概览

入口：竞赛浏览页右上角创建按钮；已有比赛进入 `/admin/competitions/比赛ID`。平台管理员和本比赛获授权的 Owner、Manager、Judge、Observer 可进入；不同角色的菜单/按钮不同，见 [权限说明](../../guide/roles.md)及 [管理入口](../index.md)。

## 创建表单

| 字段 | 填写方式与影响 |
| --- | --- |
| 标题、说明 | 明确赛事对象、规则链接、联系方式；标题用于后续危险操作确认 |
| 模式 | CTF / AWD / AWDP / KoH / LiveSolo；决定题库和对应规则分支 |
| 开始、结束 | 两者都填写，开始早于结束；本地时间转服务器时间，核对时区 |
| 自动审核 | 关闭时报名进入 Pending，开启时合法报名自动获批 |
| 赛中报名 | 是否允许 Running 中组织变更和重新报名 |
| 最大成员数 | 按队伍规则填写，约束成员加入 |
| 每队并发 Runtime | 必须覆盖实际模式需求，特别是 AWD 每队所有题目 |
| 咨询额度 | 本队同时活跃咨询、工作人员回复前可追加消息数 |
| 题目负责人处理咨询 | 是否允许对应模板负责人参与题目咨询 |
| CTF 赛后练习 | 决定结束后适用队伍的练习访问 |
| 仅工作人员 | 限定访问范围，和 Draft/发布状态是独立设置 |
| 海报 | 可选 JPEG/PNG/WebP，实际内容和大小由上传端点校验 |

## 创建步骤

1. 打开创建弹窗，填写标题、模式、起止时间与组织规则。
2. 核对时间顺序、人数和 Runtime 额度。
3. 按需选择海报后提交。
4. 创建完成后关闭弹窗，确认列表已选中新比赛并显示 Draft。
5. 进入概览，再配置模式规则、题目与协作者。

比赛创建和海报上传是两次操作。比赛已创建但海报失败时，界面可重试海报上传或完成创建；不要重新创建另一场同名比赛。后续可在概览更换海报。

LiveSolo 创建后从独立 [设置](../modes/live-solo/settings.md)、[题组](../modes/live-solo/question-groups.md)和 [赛程](../modes/live-solo/bracket.md)配置；创建不会启动共享或录像，不携带 CTF Practice 语义。

## 概览提供的操作

| 区域 | 用途 |
| --- | --- |
| 基本摘要 | 核对标题、模式、时间、Owner 和状态 |
| 海报 | 上传替换或移除，保存实际展示资源 |
| 状态操作 | 对外可见、发布、开始、暂停、恢复、结束 |
| 开赛检查 | 查看全部 Start Gate 错误，不改变为 Running |
| 生成缺失 Flag | 对当前符合条件的题目/队伍补齐缺失项，查看逐项失败 |
| 删除预览 | 检查历史与引用，决定软删除/恢复或进一步清理 |

## 更换与移除海报

选择新文件并等待上传成功，刷新海报查看实际结果；失败保留原资源，修正格式或大小后重试。移除需确认，清除当前海报显示，不等于删除比赛。上传后服务端拥有新文件引用，不能凭本地文件名确认版本。

## 开赛前检查与补 Flag

配置题目和队伍后先点击开赛检查。检查通过不等于比赛已经开始，仍需合法状态/定时开始操作。错误包含题目、队伍、配置路径和 code，按完整列表修复。

缺失 Flag 补齐是按当前定义与资格补缺，不是重置所有 Flag，也不是重新判所有历史提交。完成后检查失败数量，定位具体题目/队伍；不要把“请求成功”当作每项都成功。

## 状态和删除

当前页面根据状态显示按钮，例如 Draft 显示对外可见、Published 显示开始、Running 显示暂停，Paused 显示恢复。后台允许的转换与当前页面可见按钮范围并非完全相同，参照 [生命周期](../operations/lifecycle.md)。

结束不可恢复，软删除/恢复/硬删除/强制删除的语义分开，参照 [删除与清理](../operations/deletion.md)。
