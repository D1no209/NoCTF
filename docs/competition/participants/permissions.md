# 比赛协作者与所有权

入口：比赛管理 → 权限，`/admin/competitions/比赛ID/permissions`。Owner 和平台管理员管理此页；普通 Manager 无权替换协作者或转让所有权。当前 SPA 入口限 Administrator，后台资源权限另行执行。

## 人员关系

| 角色 | 推荐用途 | 边界 |
| --- | --- | --- |
| Owner | 赛事总负责人 | 唯一所有者，管理完整比赛与授权 |
| Manager | 配置、运行与报名管理 | 不管理 Owner/协作者权限 |
| Judge | 评测、证据与裁判操作 | 不修改基本配置、团队或生命周期 |
| Observer | 查阅和旁观管理数据 | 无写权限，内部赛道有额外限制 |

Owner/Manager 需要 Organizer 或 Administrator 平台角色，Judge/Observer 需要邮箱已验证。同一用户不能重复担任多个协作者角色，Owner 不同时列入协作者。

## 添加与调整协作者

1. 搜索候选用户，核对 UUID、平台角色和邮箱验证状态。
2. 将用户加入适用角色列表；先移除旧角色再赋予新角色。
3. 检查没有 Owner 重复或同用户跨列表重复。
4. 保存全量角色集合。
5. 重新加载页面核对持久关系，并验证需要的后台调用。

候选列表缺少用户时先确认账号与资格，不手输显示名称代替 UUID。列表上的本地添加/删除要保存才生效。

## 撤销权限

从对应角色列表移除并保存。撤销比赛协作者不删除账号或其他比赛关系，不等于令牌已经全量失效。自动化 token 泄漏需要管理员按账号 TokenVersion 撤销。

模板管理授权单独维护：能修改比赛题目不代表能修改其引用模板的技术定义。

## 转让所有权

1. 确认目标具有可担任 Owner 的平台角色。
2. 选择目标，检查当前 Owner 和目标 UUID。
3. 打开转让确认并提交。
4. 重新读取 Owner 与角色列表；旧 Owner 会成为 Manager。
5. 交接部署联系、赛事规则、Webhook 和题库权限；这些不能靠一次所有权字段变化全部完成。

转让之后重新核对页面可见动作。Organizer 降级如果仍拥有比赛/模板关系会被阻止，先完成资源移交再降级。
