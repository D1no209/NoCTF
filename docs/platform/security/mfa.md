# 平台账号双重验证

双重验证属于平台账号，对所有比赛统一生效。支持 TOTP 验证器、一次性恢复码，以及按提供方配置的 OIDC MFA 登录信任。Bot 和内部服务凭据沿用原有认证、权限和令牌有效期；MFA 管理仅面向人类账号。

## 绑定和登录

在头像菜单 → 账户安全 → 双重验证中开启。初次绑定需要五分钟内完成的密码或 SSO 登录。扫码或复制密钥后输入验证器验证码，保存仅显示一次的十个恢复码。没有验证邮箱或平台 SMTP 尚未配置时也能绑定，但不能使用邮件恢复。

已绑定账号每次完整登录都要完成第二步。恢复码仍须先通过密码或 SSO 验证，每个只能使用一次。验证期间刷新页面可恢复浏览器绑定的流程；登录验证五分钟、绑定十分钟有效。验证码失败达到流程限制或账号/IP 预算后需稍后重试。更换浏览器不能继续原流程。

账户设置中的绑定、换绑、关闭和重新生成恢复码会使原登录态失效。先验证当前验证器或未使用恢复码，再完成敏感操作；换绑确认前原验证器继续有效。被策略强制要求的账号不能关闭双重验证。忘记密码只重置密码，保留验证器和恢复码。

## 平台策略

入口：平台设置 → 认证 → 双重验证。

| 策略 | 人类账号范围 |
| --- | --- |
| Optional（默认） | 自愿开启；已绑定账号仍必须验证 |
| RequirePrivileged | 管理员、组织者，以及未删除比赛的所有者、Manager、Judge |
| RequireAllHumanUsers | 所有人类账号 |

账号详情可额外要求单个人类账号开启。启用强制策略的管理员必须已经绑定本地验证器、验证邮箱，并配置完整 SMTP 与公开邮件链接地址。管理员也遵守策略。尚未绑定且没有合格 OIDC MFA 证明的强制账号只能进入绑定流程，完成前没有业务或实时连接权限。

首次发布时所有人类账号需重新登录，旧人类 JWT 缺少认证上下文会被拒绝。既有 Bot 令牌继续有效。人类账号要求 MFA 时，管理员或 Bot 调用者均不能直接为其代签完整登录令牌。

## OIDC MFA 信任

提供方信任默认关闭。接受精确、区分大小写的 `acr`，或某组 `amr` 的全部成员；额外成员可以存在。认证时间 `auth_time` 默认不超过 300 秒，并通过 `max_age` 请求新鲜认证。

仅使用校验签名、发行方、受众、有效期和 nonce 后的 ID Token 声明。UserInfo 和浏览器标志不能证明 MFA。ID Token 无效会拒绝 SSO；仅 MFA 证明不合格时回到 NoCTF 验证。CAS 使用 NoCTF 第二步。

OIDC 信任仅用于登录。管理验证器、恢复码、策略、信任规则和管理员恢复都需要再次验证本地因素。撤销或修改信任会使依赖该证明的登录态失效。

## 恢复验证器

还有恢复码时，用恢复码完成登录，再在账户安全中换绑。全部因素丢失时，管理员先人工核验账号归属，填写核验记录，完成自身本地二次验证，再从平台用户详情发送恢复授权。

授权发送到目标已验证邮箱，30 分钟有效且只能兑换一次。邮件路径为 `/auth/mfa/recovery`；打开后立即移除地址栏令牌。用户仍须完成密码或 SSO 验证，并确认新验证器，授权不能直接登录或关闭 MFA。

最后一位管理员丢失全部因素时，在服务器使用同一部署配置、数据库和密钥执行：

```sh
dotnet NoCTF.Host.dll --mfa-recovery-user=administrator@example.com --mfa-recovery-reason="Verified by deployment operator"
```

命令只接受有效的人类管理员，不输出授权令牌。运行中的 Worker 会投递恢复邮件；执行命令不降为单因素。邮箱未验证或 SMTP 不可用时先修复恢复条件。

## 发布与运维

先以 Optional 发布，管理员实际验证绑定、恢复码和邮件恢复后，再手动开启 RequirePrivileged。Refresh JWT 保持固定 30 天；刷新不会更新主认证或 MFA 时间，也不会延长 MFA 完整登录的 30 天上限。

API 按当前账号、凭据版本和策略授权；实时连接在连接、方法、私有推送前检查，并以每五秒批量复核补偿失效通知丢失。数据库或密钥不可用时拒绝授权。

关注验证失败、限流、受限恢复授权、安全活动、待发邮件、SMTP 和鉴权依赖故障。邮件在提交后投递，未完成投递可以重新派发；同一邮件只有一个活跃派发者。SMTP 成功但派发状态未保存的故障窗口可能导致重复邮件，授权仍然只能消费一次。

所有节点需共享签名和密钥保护配置，可靠同步系统时间。不要记录验证码、密钥、恢复码、邮件授权或原始 ID Token。启用 MFA 后只能回滚到保留同等 MFA 校验能力的版本。
