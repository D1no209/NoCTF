# 平台信息、名称与 Logo

入口：平台设置 → 平台信息，`/admin/platform`。信息读取与品牌表单由两个请求加载，失败时先修复读取，不能靠在空表单保存覆盖旧配置。

## 名称和说明

填写非空平台名称和可选说明，保存后重新载入验证。空说明按空值处理；名称用于站点导航、页面标题和分享信息，不是数据库名或 Docker 项目名。

保存当前分区只更新 branding，不会切换邮件、SSO 或 Runtime Provider。不要因改平台名称一并重命名持久安装目录。

## 上传 Logo

点击 Logo 上传选择真实受支持图片，等待上传成功和服务器返回的 URL，再检查导航与公开页面。旧对象清理由文件生命周期处理，不手工删除 uploads 中猜测的文件。

文件名正确不代表图像内容有效，格式、尺寸、动画帧和像素等规则由上传端点校验。失败先检查提示，保留原 Logo。

## 公开元数据验证

平台名称、描述和 Logo 会供 API 的 SPA HTML fallback 生成元数据。更新后检查公开页面的标题、分享图与链接 Origin，而不是只看已登录浏览器内存里的标题。

域名变更仍需部署 Origin、SSO、Cookie、文件 HTTPS 和代理同步，不靠名称/说明字段处理。默认前端 ssr:false 不表示分享元数据全部只能由浏览器生成。

## 平台信息区

按实际响应查看当前版本和可用运行信息，用于排障时与部署 digest 对照。此页不替代 Docker/Kubernetes 的角色、存储和镜像状态查询，不从 UI 版本文本推断所有基础依赖已升级。
