# 账号删除预览与匿名化

入口：平台设置 → 用户 → 用户详情 → 删除。不可逆操作有独立预览，不与 Banned/Disabled 状态切换混用。

## 先看预览

预览包含 CanHardDelete、CanAnonymize、自身删除/最后管理员保护和每类业务引用数量。常见引用有比赛 Owner/协作者、模板 Owner/Manager、队长/成员、GameplayFact、Patch、通知与比赛事件。

预览只是当前检查结果，实际提交仍重新校验。不要为了让数量为零直接删除其他比赛历史或手工清外键。

## 两种模式

| 模式 | 适用情况 | 影响 |
| --- | --- | --- |
| HardDelete | 没有阻塞业务引用且保护条件允许 | 物理删除账号 |
| Anonymize | 需要保留关联比赛历史而去标识化 | 保留历史引用，永久匿名化账号 |

匿名化不是软删除，可以随时切 Active 的承诺不适用。它不级联抹掉队伍、事实和成绩，也不等于删除比赛。

## 执行步骤

1. 核对目标 ID 和当前账号状态。
2. 获取预览，阅读引用类型/数量及允许的模式。
3. 需要交接资源时先转让比赛/题库 Owner，处理管理关系。
4. 选择允许模式，填写 3–500 字符原因。
5. 阅读确认并提交一次。
6. 列表/详情检查 PhysicallyDeleted 或 Anonymized，保存审计线索。

## 保护条件

禁止管理员在该流程删除自己；不能删除/匿名化最后一个 Active Human Administrator。已匿名化账号不能再次走同样可变管理流程。

HardDeleteBlocked 返回预览时重新检查引用，别将它误读为网络故障。需要保留可恢复管理入口时先创建/验证其他有效管理员，再处理原账号。

## 隐私与历史

匿名化用于保留业务关联，不承诺已经合法导出的外部文件、聊天内容或公开截图会同步消失。内部审计、成绩和资源记录按各自保管政策处理，导出前核对授权范围。
