# 账号、角色与访问令牌

平台 Administrator 从“平台管理 → 用户”管理账号。至少保留一个 Active Human Administrator，避免失去可交互登录入口。

## 查询、详情与私有资料

入口 `/admin/platform/users`。按关键字、平台角色或 Bot 种类、SSO Provider 筛选，列表采用页码分页，改筛选回第一页。支持按外部身份 Subject 查找时仍通过受控管理入口，不将 Subject 作为公开姓名。

打开目标详情核对 UUID、UserKind、角色、AccountStatus、邮箱验证和 SSO 摘要。详情抽屉保留列表，切换用户后确保按钮作用于当前目标。私有资料通过单独授权面板读取，不用公开个人页推断用户邮箱/来源信息。

## 状态与邮箱验证

| 状态 | 管理含义 |
| --- | --- |
| Active | 正常可用，仍受具体比赛权限约束 |
| Banned | 平台账号封禁，不同于单场队伍 Ban |
| Disabled | 平台停用 |
| Anonymized | 不可逆去标识状态，不能按普通状态下拉恢复 |

角色、账号状态和邮箱验证各自保存。管理员可标记/撤销邮箱验证，成功后列表与详情应一致；被匿名化账号不可修改，最后有效 Human 管理员有保护限制。

Bot/Token/模拟的操作详见 [令牌手册](./tokens.md)，危险删除先看 [引用预览](./deletion.md)。

## 账号种类与角色

Human 支持注册、密码、邮箱和刷新会话。Bot 只由管理员创建，不能密码登录、改密码或刷新 Token；Bot/UserKind 不代替 User/Organizer/Administrator 角色。

为主办方授予 Organizer，再通过具体比赛/模板的权限授予资源管理关系。管理员角色覆盖全平台，谨慎授予。

## 更改角色与状态

搜索目标用户并确认 UUID，不仅凭同名显示文本操作。角色变更、密码重置和全量令牌撤销会使旧 Access/Refresh 失效，需要重新登录。

Organizer 降级前若仍是未删除比赛/题库的 Owner 或 Manager，平台可返回 409 与阻塞资源。先移交所有权/管理权限，再降级；不要绕过关系检查。

停用或封禁平台账号与比赛封禁队伍是不同作用域。前者影响平台身份，后者影响具体赛事竞争资格；操作前确认目标范围。

## 为 Bot 配置 API 使用

1. 创建 Bot，填写显示身份和需要的平台角色。
2. 赋予具体赛事/题库授权。
3. 为目标 Active 账号签发普通 Access JWT。
4. 将 token 放入外部程序 secret store，使用 Bearer Header。
5. 测试所需读取/写入，再检查无权限资源被拒绝。
6. 记录过期时间与轮换负责人。

管理员可签发 60 秒至 1 年的访问 JWT，不生成目标 Refresh Token，不建立设备会话。平台不保存该 token 的可单独吊销记录；全量撤销递增目标 TokenVersion。

## 身份模拟

SPA 身份模拟切换为目标的普通访问 JWT，并在内存中保存原管理员 JWT。当前页面不允许嵌套，刷新后通过原管理员 Refresh Cookie 恢复。

模拟时明确当前身份再操作，以目标权限验证页面；后端没有额外“模拟管理员绕过”。查看实际选手行为优先使用隔离测试账号，避免误改正式队伍。

## SSO 绑定管理

按 Provider/Subject 搜索和查看绑定摘要，必要时解除绑定。解除递增 TokenVersion；审计不记录 Subject 原文。外部身份没有自动赋予 Organizer/Admin 的角色映射。

账号敏感资料、JWT、密码和绑定凭据不要写到公告或日志。排障使用账号 UUID 和事件时间，通过授权管理入口查看所需详情。
