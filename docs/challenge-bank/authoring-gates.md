# 题目编写门禁

保存草稿与实际使用分别校验。

| 操作 | 校验要求 |
| --- | --- |
| 新建模板 | 基本信息、至少一种合法能力；容器与能力参数可以后续填写 |
| 保存详情 | 基本信息和数据结构合法；允许缺少执行所需配置 |
| 复制模板 | 合法材料结构；允许复制尚未配置完成的材料 |
| 能力测试 | 只校验本次需要的能力；其他未完成能力不会阻止测试 |
| 启动环境、Fix 测试 | 校验实际运行环境和命名服务契约 |
| 投放、发布、开赛 | 按对应消费场景校验必需能力及完整配置 |

仅修改标题或题面不禁用测试和投放。技术配置尚未保存时，需要先保存再使用，避免将草稿当作实际执行材料。

活动能力执行只保护它使用的能力；已经结束的模板能力测试不阻止继续编辑其他能力。仍保留权限校验、数据格式与长度限制、保留环境变量限制、业务引用保护、活动运行环境保护和未保存离开提示。
