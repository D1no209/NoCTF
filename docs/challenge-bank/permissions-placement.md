# 模板权限、引用位置与删除

入口：模板详情的负责人/管理者分区及比赛引用位置区域。模板权限和比赛权限独立。

## 授权模板管理者

当前 Owner 是模板负责人，Manager 列表给予模板管理。候选需要对应 Organizer/Administrator 资格；Owner 不重复放入管理者列表。

搜索并核对用户 ID → 加入/移除管理者 → 保存 → 重新读取 → 使用目标账号验证必要操作。被授权编辑比赛并不自动拥有模板 Flag、附件对象键或技术定义编辑权限。

## Shared 与 Private

Shared 让其他组织者查看题面并引用，不等于原始 Flag 与内部定义公开。Private 限制新可见/引用范围，但修改可见性不能假定已经存在的比赛引用被自动销毁。

正式比赛使用共享模板前明确维护者和后续修改政策。更换权限后不要以题目标题相同判断来自同一模板。

## 查看引用位置

“比赛引用位置”展示模板被哪些 CompetitionChallenge 使用，核对比赛标题、状态与实例 ID，然后跳转到对应比赛题目。修改技术定义前先检查正在进行的引用。

模板题面/元数据供引用方读取，下一次 Runtime 启动/重置使用最新定义，已有实例不自动更新。模板分区保存彼此独立，Runtime dirty 状态不是模式定义保存成功的证明。

## 删除和恢复

存在未删除比赛题目引用时不能删除模板，活动实例或进行中模式变化也可能被拒绝。先解除合法引用/停止对应环境，再按页面确认操作；删除模板不是批量清成绩。

题库列表启用包含已删除可找到恢复入口。恢复后重新检查 Shared/Private、权限、附件/Flag、技术定义及引用，不直接发布到所有赛事。

## 交接建议

交接模板 Owner/Manager、镜像仓库读取和出题附件保管，分别确认。比赛所有权转让不会自动转让题库或 Registry 凭据。
