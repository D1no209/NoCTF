# 理论题库

理论题库位于 `/admin/theory/questions`，与包含 Flag、Runtime 的实践题库分开。题目可用于个人练习、限时测验，以及 CTF、AWD、AWDP 的比赛理论答题。理论答题不增加新的比赛赛制，KoH 和 LiveSolo 不配置比赛理论试卷。

## 创建与校对

1. 打开理论题库，点击新建，进入 `/admin/theory/questions/new`。
2. 填写标题和题面，选择单选、多选或判断题，以及基础、中等或进阶难度。
3. 添加选项并标记正确答案。单选只能有一个正确项；多选至少有两个正确项；判断题必须有真、假两个不同语义的选项，且只有一个正确项。
4. 填写解析、知识点和标签，方便后续筛选组卷。题面和解析使用安全 Markdown；需要图片时通过页面上传，不依赖外部图片自动加载。
5. 保存后重新打开详情 `/admin/theory/questions/题目ID`，核对题型、选项、答案和图片。将准备投入使用的题目设置为 Available（可组卷）。草稿和停用题目不能作为新的可用候选。

标题最多 160 字符，题面及解析各最多 64000 字符；选项为 2–8 个，每项内容最多 16000 字符。知识点和标签会去掉首尾空白并按大小写不敏感去重。判断题的真假含义与显示顺序分开，不能用“第一项始终是真”出题。

判分采用完整答案集合：选择与正确集合完全一致才得该题全部分数；少选、多选、错选或未作答均不得分，没有多选部分给分。出题时应在题面写清要求。

## 查找与维护版本

列表支持题型、状态、难度、知识点和标签筛选。选中题目后先查看已发卷引用和曝光情况，再决定编辑、复制或停用。

内容修改形成新版本。已发布活动冻结自己的候选版本，修改题库不会替换已经发布或发出的试卷。发现正式活动答案有误时，使用 [答卷审核与纠错](../competition/judging/theory.md)，不能仅修改题库后等待旧成绩自动变化。

复制和新版本保留规范题源身份。改名、复制、停用或删除关联比赛，都不能清除已发生的题源曝光，也不能绕过跨卷重复题源检查。

## 使用、编辑与管理授权

| 授权 | 工作范围 |
| --- | --- |
| Use（使用） | 将获授权题源纳入组卷候选，不因此获得答案键或图片读取权 |
| Edit（编辑） | 在授权范围内维护题目内容与版本 |
| Manage（管理） | 管理题目及其授权，包含较低级能力 |

从题目详情维护授权，核对被授权账号与级别。能组织比赛不代表可以编辑所有理论题；能使用某题也不代表可以浏览它的受保护材料。图片每次访问仍检查权限，复制图片地址不能扩大读取范围。

## 组卷前检查

先准备足够的可组卷题源，再在 [比赛理论答题](../competition/content/theory.md)或 [独立理论活动](../competition/activities/theory.md)中填写抽题规则并验证容量。容量同时受题型、难度、知识点、标签、曝光、已使用来源和剩余尝试次数影响；列表中有足够题目不等于一定能够完整组卷。
