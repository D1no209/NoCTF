# 导航、个人资料与外观

## 顶部导航

当前导航提供竞赛、题库管理、平台设置和消息中心，按登录身份/权限显示。右侧提供中英切换、主题颜色、明暗主题和头像账号面板。

管理入口不可见时先检查角色与当前页面权限，不只手工输入 URL。比赛管理从选中赛事的工作区进入，见 [管理入口](../competition/index.md)。

## 账号面板

点击头像打开账号面板，从身份摘要进入个人页，账户安全等设置在下方展开。登录/注册是独立 `/auth/login`、`/auth/register` 页面，正常登录后按受限站内 redirect 返回原目标。

改密码、绑定/解绑 SSO 通过账户安全；头像/资料更新不等于更改后台角色。令牌与设备能力边界见 [账号说明](./account.md)。

## 头像和个人标签封面

上传支持的图片，使用裁切器调整位置、缩放和旋转，再确认上传。头像和个人标签封面是不同资源；封面采用宽幅 4:1，不能用个人壁纸设置代替。

上传后重新打开公开个人页检查实际裁切与显示，图片格式/像素/大小失败按反馈修正。只改变本地预览不代表服务器已保存。

## 公开个人页

个人页展示当前允许公开的身份、赛制分布、方向统计、近期赛事和有效勋章。方向统计按公开且已开赛赛事的已发布题目形成，不应期待草稿/内部测试都成为公开画像。

方向少于三个时可能显示数值列表，不强行生成雷达。点击勋章查看详情；当前有效授予可能随闯关失活撤销，历史得到不意味着永远显示。

## 语言和主题

语言切换主要影响平台固定文案，不自动翻译组织者自己写的题面/公告。主题颜色与明暗偏好保存于当前浏览器，亮暗分别维护；恢复默认清除本地覆盖，不改变所有用户的平台品牌设置。

减少动态效果由用户/系统偏好影响，动画变化不改变提交、计分和管理权限。设备间偏好不应被当作跨设备业务配置。

## 首页终端

首页伪终端支持 `help`、`ls`、`status`、`whoami`，回车执行当前可支持命令并替换输出。它不是宿主 shell，不运行任意服务器命令，也不保存浏览器终端历史。
