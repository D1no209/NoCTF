# 排行榜与赛后练习

## 阅读排行榜

从比赛进入“排行榜”，选择适用赛道，核对当前展示范围、总分和题目详情。不同模式有不同并列规则，不只按解题数量排序。

排行榜从当前有效比赛事实计算。正确提交完成后，Worker 合并相关事件并重建，页面收到提示后刷新；短暂延迟时先看提交最终结果，不重复提交。

## 分数为什么会改变

| 原因 | 对成绩的影响 |
| --- | --- |
| 动态重算 CTF 后续解题 | 既有解题基础分可能降低 |
| AtSolve CTF 后续解题 | 正常情况下既有解题价不因新队解题改变 |
| 提示/错误罚分 | 规则对应的扣分 |
| 重判和人工调分 | 当前事实或额外人工事实进入投影 |
| 队伍被封禁/恢复 | 资格及相关攻防事实重新投影 |
| 修改赛道 | 历史事实按当前赛道规则重算 |
| 组织者调整计分配置 | 新配置应用于历史权威事实 |

`AtSolve` 不表示永远不允许历史成绩变化，它仍以当前事实和规则重建。

## 可见性状态

- **Live**：展示当前公开投影。
- **Frozen**：展示冻结时的公开投影，之后的新结果不立即公开。
- **Blackout**：公开榜单隐藏。

管理者拥有的读取范围可能与选手不同。冻结或隐藏时不要据公开页面断言后台没有处理提交；若自己正确结果已确认，等待赛事公布。

赛道的“计分”“参与血榜”“影响动态分值”“公开排名”等开关独立。内部测试赛道不参与公开竞争，因此测试队完成题目不应被当成正式榜选手。

## 赛后练习

仅 CTF 可以由组织者显式开启赛后练习。已获批且未封禁的原队伍，以及赛后按练习规则获批的新队，可在适用已发布容器题启动独立 Practice Runtime。

练习不复用正式 Runtime。Flag 提交仍有结果记录，但发生在正式窗口外，不增加正式分数、血奖或正式榜；赛后新队也不进入正式排名。闯关和勋章可以根据当前正确事实重算，勋章仍不加分。

没有练习入口时联系组织者确认是否开启、题目支持和本队资格。比赛结束后的组织资料与追加成员限制仍然有效。
