# 消息、咨询与题解

## 消息与赛事动态

平台包含三个相关入口：

| 入口 | 阅读目的 |
| --- | --- |
| 全局消息中心 | 官方通知以及与账号、队伍或管理职责直接相关的消息 |
| 比赛“动态” | 追溯有权看到的赛事状态和操作事件 |
| 题目“赛事播报” | 一二三血、公开封禁/纠正、提示、题面更新和开放等摘要 |

赛事播报仅向本场已审核通过且未封禁的参赛队伍及获授权的工作人员显示。未报名、待审核或被拒绝时不显示播报入口，也不加载播报数据；审核和成员资格变化后自动更新，失去资格时清空已加载内容。

它们不是同一份个人收件箱。收到赛事公共播报不代表事件发生在自己的队伍。实时断线重连后重新读取页面，SignalR 不补发全部历史。

## 向组织者提问

在比赛“咨询”工作区创建问题，填写清晰标题、复现描述并按需要关联题目。需要权限时先确认报名 Approved。不要在公开内容中披露完整 Flag、密码或队伍邀请码。

建议问题包含：题目名称、实际 Runtime/尝试 ID、发生时间、预期行为、实际错误和已经尝试的步骤。管理员或裁判回复后在同一线程继续沟通，不为同一故障反复建线程。

问题根、回复和状态变化属于同一咨询线程。回复上下文只是辅助引用，线程成员由根问题决定。题解审核发起的队伍私密咨询也在此工作区处理。

## 单题题解

比赛管理者开启单题题解后，题目标题旁会出现“单题题解”入口，“我的题解”增加单题页签。不同比赛的投稿和查阅记录独立，尚未解出也可以投稿。

选择 Markdown 或 PDF，先“保存草稿”，再“提交审核”。Markdown 可编辑、预览或分栏显示；PDF 上限为 64 MiB。草稿显式保存，Ctrl/Cmd+S 可保存 Markdown；退出未保存编辑器时会提示。每队每题只有一份投稿，全队共享，并发编辑发生冲突时保留自己的未保存内容，重新加载后再协调修改。

公开后修改会产生新版本，旧公开版本在新版审核期间继续可读。历史版本只读，退回原因和提交者、时间可在版本历史中查看。单题截止时间独立于整场 PDF，页面显示实际日期；截止后不能修改投稿。自己的内容免费查看，但不会因此解锁他人的内容。

公开列表只提供作者、格式、版本和发布日期。首次阅读官方或他队题解时，必须先确认计分影响，浏览列表或切换条目不会扣分。确认后，全队共享本题查阅资格；成员、题解或版本变化均不会重复扣分。

正式赛中查阅会按首次确认时的比例折扣本队本题的正向收益：`扣分 = ceil(正向收益 × 百分比 / 100)`。无收益时不扣总分，之后取得收益再折扣；原有罚分、提示费用和人工调分保持原值。比例后续修改不追溯已有查阅。CTF 先查阅再解题不能获得血榜资格，即使比例为 0%；已经取得的血榜保留，奖励参与折扣。

暂停时不能首次解锁，但可以阅读已解锁内容。赛后免费阅读不新增正式扣分，之前的折扣仍保留。管理员撤下内容或关闭功能后，正文不可读，已有查阅与成绩记录保留。读取失败可重试；PDF 通过浏览器原生下载，传输中断不会重复收费。

查阅题解不替代附件下载或容器启动证据；静态 Flag 获取证据检测继续生效。

## 提交整场 PDF 题解

1. 进入比赛“我的题解”的“整场 PDF”页签。
2. 阅读是否强制提交、截止时间、当前允许的大小。
3. 选择有效 PDF 文件，按题目编号组织解题内容。
4. 提交并检查文件名、提交时间和预览。
5. 截止前可以替换当前 PDF，确认最终版本正确。

队伍成员均可更新当前题解，协调好最后提交者。仅改扩展名不能将其他格式变成有效 PDF；平台检查 MIME、文件头和大小。文件上限以页面显示和当前部署配置为准。

未强制提交的比赛仍可自愿提交。截止后不能补交或替换，已有文件可按权限查看和下载。提交按钮成功后要确认预览内容，避免把空白版或错误文件当作完成。

## 审核与调分

组织者可结合当前题目得分审核 PDF、发起私密咨询和人工调分。PDF 上传本身不自动等于加分；调整产生单独事实并刷新权威排行榜。收到审核咨询时按证据回答，并保留本队原始解题材料。

需要申诉作弊封禁时使用队长的对应申诉流程，普通题解咨询不能代替封禁申诉。
