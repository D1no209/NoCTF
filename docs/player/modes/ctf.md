# CTF 参赛流程

1. 报名获批，等待比赛和题目开放。
2. 阅读题面、下载附件，按需启动本队 Runtime。
3. 得到答案后提交 Flag；补丁验证交互题按题面提交修复包。
4. 查看正确结果、解题奖励、血奖、提示扣分和错误扣分。
5. 开启闯关时先完成前驱题或勋章条件，再进入后续题。

CTF 分值可能固定或动态衰减。`DynamicRecalculation` 会随后续解题重算既有基础分，`AtSolve` 按解题位置结算；配置、资格或重判变化仍可能重新计算历史成绩。以当前权威榜单为准。
