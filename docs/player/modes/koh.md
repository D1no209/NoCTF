# KoH 参赛流程

所有队伍攻击同一共享 Hill。每队读取自己的 Control Flag，并通过题目规定的方法让控制检查端点返回本队 Flag。平台定期轮询，匹配到唯一有效队伍后按间隔给分。

KoH 不通过普通 Flag 提交按钮申报控制权，也不为每队创建一个 Hill。仅本队 Flag 可被读取，不能查询别人 Flag。检查端点的正文应为精确 UTF-8 Flag，不附加 JSON、换行或说明文本。

控制是每次轮询独立判断。超时、错误内容或服务不可用不会延续上一次成功控制计分；暂停停止轮询，不补跑缺失观察。
