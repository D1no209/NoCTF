# AWD 参赛流程

AWD 每队拥有自己的目标，平台按轮次换 Flag 并持续检查服务健康。加固期先修复本队服务，比赛攻击阶段获取其他队有效 Flag 后提交；自己的 Flag 不当作攻击结果。

重点核对当前轮次、目标信息和服务状态。Flag 只在对应有效窗口计分，过期内容不能跨轮复用。服务可访问不等于 Checker 健康，修复时同时保留题目规定的正常功能。

暂停会停止相应竞技调度，轮次按有效运行时间延后；恢复后跟随平台展示的当前轮次，不按自己计算的墙钟持续攻击。
