# AWDP 参赛流程

| 动作 | 提交内容 | 完成标准 |
| --- | --- | --- |
| Break | 目标中正确 Flag | Flag 最终正确 |
| Fix | 按题目要求制作的 archive | 正常功能与漏洞修复检查通过 |

Break 不是上传 exploit 文件，Fix 不是另一种 Flag。赛事可要求先 Break 才 Fix，并分别限制次数、设置分值和失败扣分。

制作修复包时保持指定目录结构、入口文件和依赖约定。平台会检查格式、哈希和解包限制；符号链接、绝对路径、路径穿越或过度展开的包会被拒绝。

提交后若赛事采用手动评测调度，需要等待裁判派发。保存已受理的记录，不因为仍在 Pending 就反复上传相同文件。查看具体结果区分 exploit 仍成功、正常服务异常和平台故障。
