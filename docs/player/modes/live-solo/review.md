# LiveSolo 历史题目与结果回看

在对局工作区查看已开放题目和结果。当前合格的锁定上场成员无需等整场比赛结束即可回看；同队未上场人员、其他 Match 的成员或权限已撤销者，不自动获得材料访问权。

## 已开放题目

实际开放时固定当时的标题、正文、方向、标签、开放免费提示和附件引用。后续题库或本场材料编辑不会把这段历史替换成最新题面。

只能回看真正开放过的题目，未来题目仍不可读。旧记录缺少开放快照时显示未记录，不用现有题库内容补造历史。工作人员预览未来材料是独立授权，不代表选手也已获得访问。

随机附件只提供已分配给本队的版本，回看不会重新抽取其他版本。历史回看和工作人员下载不产生新的场内获取证据，不能补足要求获取证据的 Flag 提交。下载仍检查当前权限，旧链接不保证永久有效。

## Round 与 Match 结果

查看胜方、结束原因、实际胜局和当前结果。判胜按共同受理顺序，不按通知先后；超时后可能先确认结果，等待已受理记录处理。

弃权保留真实已有胜局，不补造未打轮次。作废或无胜方超时不算某队取胜；纠正引起的下游替换会标示原因。无法证明的历史分数或原因显示“未记录”。

结果面板可手动打开。自动提示按身份、Match、Round 和结果修订去重；编辑或已有对话框时延后，浏览器无法保存去重记录时仍可手动查看。没有自动弹窗不代表没有结果，已打开的旧结果也不会被后续修订直接覆盖。

## 回看、公开节目与题解

历史回看遵循上场名单及资源授权；[公开节目](./program.md)遵循观众权限和延迟；[赛后题解](./postgame.md)有自己的投稿、审核和公开流程。能查看自己的历史题目不代表内容已可对外发布。
