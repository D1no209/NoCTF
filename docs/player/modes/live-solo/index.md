# LiveSolo 参赛流程

LiveSolo 与 CTF、AWD、AWDP、KoH 同属平台赛制。本页面向队长、上场成员和观众：按 Match/Round 竞技，使用共同受理顺序中的第一条有效 Flag 判胜，累计胜局，不使用普通题目积分或血奖。

## 阅读顺序

| 任务 | 操作说明 |
| --- | --- |
| 锁定上场名单、确认准备、主动共享 | [对局准备](./preparation.md) |
| 已开放题目、附件、Runtime、Flag 和时限 | [场内解题](./playing.md) |
| 入场名额、延迟视频和比分 | [观赛](./program.md) |
| 按 Match/Round/Question 查看或提交题解 | [赛后题解](./postgame.md) |

先确认本队报名资格、当前账号 MFA 和本场锁定名单。未上场成员不因同队身份自动拥有场内资源；观众使用延迟节目，不获得裁判原始屏幕或当前状态。

需要筹备、裁判或纠正结果时阅读 [比赛管理](../../../competition/modes/live-solo/index.md)。媒体安装与正式启用条件分别归入 [安装部署](../../../installation/live-solo-media.md)和 [运维验收](../../../operations/live-solo-readiness.md)。

当前真实全员采集、多节点恢复和完整生产容量仍有验收边界，不因界面可创建对局就视为完成正式投产。
