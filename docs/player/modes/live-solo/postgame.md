# LiveSolo 赛后题解

入口：`/competitions/比赛ID/live-solo/postgame/对局ID`，具体题目为 `/postgame/对局ID/轮次ID/题目ID`。目录区分 Round、重赛次数和 RoundQuestion，不用普通 CompetitionChallenge 地址绕过作用域。

## 目录与权限

从历史目录选题，核对原 Round 和重赛版本。赛前、赛中和没有明确作用域的普通正文请求不能读取赛后题解；赛事结束后合格读取者按当前资格访问。

页面提供 Public、Mine、Official、Review 等能力相关页签。不是所有账号都有官方编辑或审核按钮，工作人员读取不表示可以代表某队投稿。

## 投稿

选择 Markdown 或 PDF，先保存草稿再提交审核。检查未保存提示；多人编辑发生版本冲突时保留草稿并重新加载协调，不覆盖另一位成员修改。

队伍投稿须功能已启用、允许投稿且未过显示截止。官方内容由相应管理者维护，审核/发布角色沿用当前题解能力。

## 审核和读取

工作人员检查当前版本、提交者和正文，按允许动作退回、公开或撤下并记录原因。PDF 使用短期预览和原生下载，逐请求核对当前权限；授权失效时不保留旧私有文件视图。

赛后合格队伍读取免费，不创建普通题解解锁事实，也不为 LiveSolo 写普通积分收益折扣。CTF 查阅题解的血榜/折扣规则不能直接套用。

## 静态内容的曝光

公开静态题解会形成规范来源曝光，影响后续尚未开始 Match 的合法用题。删除源、再次复制或换题解标题不能移除已经发生的曝光。

不能把一次 PDF 预览/下载成功当作所有格式、多用户和完整赛后发布链路都已验收；正式使用仍按 [就绪检查](../../../operations/live-solo-readiness.md)走完整流程。
