# 建队、邀请与报名

NoCTF 按队伍参赛。建队、加入队伍和正式报名是不同步骤；必须提交报名并获得 Approved 状态，才能访问参赛私有内容。

## 1. 查看赛事要求

打开比赛概览，确认模式、开始/结束时间、人数上限、报名窗口、是否需要审核和赛道条件。Visible/Published 通常可报名；Running 是否允许由赛事“赛中报名”开关决定，Paused/Finished 不能进行普通组织变更。

同一账号在同一比赛只能加入一队。Bot 与普通账号按同样的队伍权限边界处理，不能借多个账号替另一队读取私有 Flag。

## 2. 创建队伍草稿

1. 登录后在赛事概览选择建队。
2. 填写队名、头像，赛道启用时选择可报名赛道。
3. 保存，成为该队队长。
4. 打开“我的队伍”，完善资料和成员。

新队伍为 **Unregistered（未报名）**。赛道邀请码或 SSO 尚未准备好时也可以保存草稿；这些条件在提交报名时统一检查。

## 3. 邀请成员

队长获取队伍的 32 字符邀请码，私下发送给队员。队员在该赛事选择“凭邀请码加入”，输入完整 token。持有 token 即可直接加入，不存在待邀请确认、邀请期限或单用户邀请列表。

邀请码是队伍加入凭据，区分大小写，不是赛道准入码。泄露后队长可轮换，旧 token 立即失效。轮换邀请码不改变报名状态，但实际加入/退出成员会使队伍回到未报名。

如果加入失败，检查是否已在别队、邀请码已轮换、成员数上限、比赛组织变更窗口或队伍被封禁。

## 4. 提交报名

队长在赛事概览/我的队伍的报名入口提交当前草稿。赛道启用时填写当前赛道要求的邀请码，并确保全体成员满足该赛道的 SSO 条件。

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| Unregistered | 草稿尚未报名，或组织资料发生变化 | 完善后提交 |
| Pending | 等待组织者审核 | 等待批准/询问组织者 |
| Approved | 已通过报名 | 等比赛与题目开放 |
| Rejected | 未通过本次审核 | 根据原因修改后重新提交 |

自动审核开启时，符合条件的报名直接成为 Approved；否则进入 Pending。Unregistered/Pending/Rejected 不具有题目详情、附件、提示、咨询、Flag 或 Runtime 权限。

## 5. 组织变更需要重新报名

实际改变队名、头像、赛道、成员关系或队长后，队伍退回 Unregistered，需要重新提交和审核。保存相同值或轮换邀请码不会造成这一变化。

若已 Approved 后再加入队员，不要以为其他队员仍能继续参赛。已有 Runtime 可能保留到正常结束，但选手读取和操作权限会被拒绝，直到再次 Approved。

转让队长前确认目标已是本队成员，完成后由新队长处理报名。队长退出前要完成必要的转让或按界面规则解散，不能产生无成员的队长身份。

## 封禁与申诉

封禁立即阻止参赛私有操作、回收适用的 Runtime，并影响排行榜资格。队长可以针对对应封禁提交一次私密申诉，全队可读，由有权限的管理者裁决。不要重复向多个页面提交同一申诉，也不要把证据和私人原因发到公开播报。

接受申诉可恢复历史投影；比赛已经 Finished 时不会重新部署正式 Runtime。

## 赛后新队伍

CTF 开启赛后练习时，Finished 阶段可按练习入口加入的新队自动审核，用于练习而不进入正式榜。正式结束后不能继续编辑组织资料或追加成员；提前规划参加练习的账号和队伍。
