# 理论答题

个人练习与限时测验从 `/theory` 选择活动，进入 `/theory/活动ID`。比赛理论答题位于 `/competitions/比赛ID/theory`，仅在主办方为 CTF、AWD、AWDP 配置并发布后可用。

## 开卷前

核对活动类型、开放与截止时间、每卷时长、剩余次数和计分方式。最高分保留有效答卷中的最高成绩；最后一次使用最后一次有效尝试；累计将有效答卷得分相加。限时测验和累计计分有有限次数，只有非累计个人练习可以配置不限次数。

比赛按队伍发卷，**全队共享一份当前试卷，任何有效成员都能答题和交卷**。先与队友约定分工；个人活动则使用自己的试卷。开卷受活动状态、资格和剩余次数检查，按钮可见不代表一定能发卷。

点击开始后等待服务器返回试卷。网络超时或多位成员同时点击时，先重读当前试卷；系统会恢复同一份已发试卷，不应反复开启新尝试。收到题源不足提示时联系主办方，刷新不能增加候选容量。

## 作答、标记与保存

在题号导航中切题，按需标记待检查题。选项次序在本卷内固定，刷新或更换队友不会重新洗牌。单选和判断题选择一项，多选题选择完整集合；多选少选或多选均无部分分。

选择后留意保存状态，区分“本地选择”“正在保存”“已保存”和失败待重试。保存答案只同步选项，不立即判分。结束浏览器会话前等待保存完成；有未同步选择时离开可能丢失本地输入。

同队多人修改同一题时可能出现冲突。页面保留未同步选择，供你比较：

| 处理方式 | 适用情况 |
| --- | --- |
| 使用远端答案 | 接受队友已保存的选择，放弃自己的未同步修改 |
| 保留本地答案并重试 | 确认自己的选择后，以最新版本重新保存 |
| 保存失败后重试 | 网络恢复后重试原操作，再检查结果 |

不要仅凭自己的页面选项判断队友已收到。队友提交、暂停或截止后，服务器可能拒绝迟到的保存，按最新状态处理。

## 交卷与到时

1. 检查题号列表中的未答题、标记题和保存失败提示。
2. 等待修改同步完成，再点击交卷，核对确认信息。
3. 如果确认期间队友改了答案或状态已变化，刷新核对后重新确认。
4. 等待最终结果；请求超时先查询试卷状态，避免将已交卷误认为未成功。

整卷提交或超时后才统一评分。到时由服务器处理；浏览器倒计时和 Worker 的实际处理延迟都不能为你延长答题窗口。活动暂停时以服务端返回的剩余时间为准，恢复后重读；比赛关联活动的延长不能超过比赛结束边界。

## 结果与再次尝试

交卷后可查看总分、满分、有效成绩、次数和状态，**不再提供本卷题面、图片、答案键或逐题对错**。这同样适用于零分答卷，不要把没有解析当成加载失败。

还有次数且活动允许继续发卷时，可开始下一次尝试。各次组卷会检查规范题源，复制题目或新版本不会被视作全新来源。已作废答卷仍保留次数与题源记录，不能通过作废无限重抽。

比赛榜单将理论分与实践分分别呈现；未交卷和交卷零分是不同状态。封榜、隐藏及纠错重算会影响对外显示，见 [排行榜](./leaderboard.md)。成绩有疑问时提供活动与试卷 ID，通过主办方咨询渠道反馈，不在公开讨论中贴题面或答案。
